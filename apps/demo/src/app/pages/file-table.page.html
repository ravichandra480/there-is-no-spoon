Keyboard

File table keyboard interaction
Key Action
Tab, Shift+Tab Move between select all, Download Selected, the table, and the check box of each available file. Files that are not available are skipped.
Space, Enter Check or uncheck the focused check box. Select all chooses every available file, or clears the choice if all are chosen.
Enter, Space On Download Selected: ask to download the chosen files. An alert lists the path and device of each one and focuses its Close button.
Escape, or Enter on Close Close the alert. Focus goes back to Download Selected.
Left and Right arrows When the table has focus on a small screen: scroll it sideways.

Accessibility notes

  • A real HTML table, so screen readers read each cell with its column name.
  • Select all shows a dash (“mixed”) when only some files are chosen. The number chosen is announced when it changes.
  • Files that cannot be downloaded have a turned-off check box that says why.
  • The download alert is read out when it opens: its title, the number of files, and the path and device of each.
  • The green dot is extra: the word “Available” always says the same thing.
  • Check boxes and the button are at least 44 by 44 pixels, with a 3 pixel focus ring.
