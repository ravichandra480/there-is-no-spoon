## Automated coverage (`button.spec.ts`)

- axe-core with WCAG 2.2 A/AA/AAA + best-practice tags on every state: primary, secondary, disabled,
  toggle off, toggle on, icon-only, submit.
- 2.5.5 target size ≥ 44×44 and 2.4.13 focus appearance (≥ 2px, ≥ 3:1) on every enabled state.
- Icon-only without `label` fails `button-name` (regression test).
- Keyboard: Enter and Space activate; Tab skips disabled, reaches enabled; events bubble and are composed.
- Contrast of all token pairs ≥ 7:1 (text) / ≥ 3:1 (boundaries, focus) in every theme — `ui-tokens` tests.
